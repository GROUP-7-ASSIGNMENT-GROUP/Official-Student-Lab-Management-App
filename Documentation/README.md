Documentation

Overview

This folder contains the documentation and design materials for the Student Lab Management App.

Contents

Requirements

"requirements.md" contains the functional and non-functional requirements of the system.

System Architecture

"system_architecture.png" illustrates how the Android application, local storage, synchronization system, backend and MySQL database communicate.

Database Design

"database_design.png" shows the database entities, attributes, primary keys, foreign keys and relationships.

Use Case Diagram

"use_case_diagram.png" shows the main interactions between students, lecturers and the system.

Purpose

The documentation provides a clear explanation of how the system is designed and how its components work together.
